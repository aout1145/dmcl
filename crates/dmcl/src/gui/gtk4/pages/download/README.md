# 下载域（新建实例）

`crates/dmcl/src/gui/gtk4/pages/download` —— 「下载 / 自定义」新建实例页及其公共组件。
整体架构见 [gtk4/README.md](../../README.md)。

目前只有「自定义」一种下载类型：用户选 MC 版本与可选的加载器，填名称后跑安装任务。

## 数据流

```text
CustomPage
├── InstanceSummary       名称 / 分类 / 图标 / 安装按钮
└── VersionSelect × 5     MC / Forge / Fabric / NeoForge / OptiFine
        │
        ▼
  自动命名 / 图标 / 冲突检查 / InstallSpec
        │
        ▼
  Shell::run(install_task) → 打开任务对话框 → 关闭页面
```

页面拥有联动与安装流程，见 [custom/README.md](custom/README.md)。`InstanceSummary` 与
`VersionSelect` 位于 `common/`，是 download 域公共组件，不是全 app 通用小部件。

## InstanceSummary

图标 + 名称 + 分类 + 安装按钮。图标菜单只有「自动」和「自定义…」两项：自动值由页面按
版本类型与加载器计算，不写文件；用户选的自定义图片在安装成功后转成 `logo.png`。预览按
原比例完整显示，不裁成圆形。
名称与图标都有「当前值 + 用户是否改过」两个状态：外部推自动值时只在用户没改过时生效，
用户改过就永不覆盖；名称清空视为从未编辑，自动命名重新接管。

名称的格式校验、`versions/<名称>` 冲突检查与安装按钮可用性都在组件内完成；页面只告诉它
「名称之外的条件是否满足」。分类可沿用已有分类，也可输入新名字。

## VersionSelect

通用版本选择器：取数器、筛选 chips、是否显示搜索框全部由页面注入，组件不认识 Minecraft。
支持空闲 / 加载中 / 就绪 / 空 / 失败五种状态；选中后收起，加载器行可取消选择。页面通过
输入消息设置上下文与冲突状态，组件通过输出消息上报选择变化。

- 列表按数据源顺序展示，带徽标的条目进入置顶区，同时仍保留在完整列表中；搜索对 id 与
  展示文案做大小写不敏感匹配。
- 取数带代际计数，上下文变化后旧响应直接丢弃；换上下文或旧选择不在新列表中时清空选择。
- 过滤是纯函数并保持数据源顺序；选中标记只更新真正变化的两行，避免大列表整表重绘。
- 用 `AdwExpanderRow` 承载展开内容，而不是 `AdwComboRow`：后者放不下分节标题与 chips。
- 展开时机由页面控制；自动展开只消费一次，用户手动收起后不会被后续状态同步重新展开。
