# 首次启动向导

`crates/dmcl/src/gui/gtk4/app/setup` —— 配置文件不存在时，由根组件在启动后打开的设置向导。
整体架构见 [app/README.md](../README.md)，GTK4 前端见 [gtk4/README.md](../../README.md)。

## 职责

一个模态对话框，依次引导用户完成：

1. **账户**：添加离线账户、Microsoft 设备代码登录、设为默认、删除；
2. **Minecraft 目录**：添加 / 编辑 / 删除目录、设为默认、拖动排序；
3. **游戏设置**：版本隔离开关。

账户页与目录页直接复用首选项里的组件，不复制登录、目录校验等逻辑；三处读写的是同一个
共享配置。

## 设计约定

- 只有配置文件**不存在**时才出现；权限错误等其它情况交给配置警告处理。
- 向导不能绕过确认直接关闭：离开只有「完成」或「跳过」两条路。
- 「跳过」先确认，确认后把当前配置写入文件；「完成」要求默认账户和默认目录都有效，保存
  成功后才关闭。跳过也会写配置，因此下次启动不再出现。
- 完成后按新配置补齐主页，并切到新默认目录的主页；跳过不切换主页。
- 完成条件等可测试的判断抽成纯逻辑，不创建 widget。
