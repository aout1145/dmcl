# 任务对话框与任务卡片

`crates/dmcl/src/gui/gtk4/app/tasks` —— 任务对话框、任务卡片、警告确认。
app 层见 [app/README.md](../README.md)，整体架构见 [gtk4/README.md](../../README.md)。

## 职责

- 展示全部安装 / 启动任务：每个 Step 的计数、任务明细、全局进度与日志；
- 支持取消任务、清除已结束的卡片；
- 处理任务发出的警告确认；
- 关闭主窗口时判断是否有未结束任务，并决定是否确认退出。

## 设计约定

- 任务列表是模态对话框；关闭对话框只是收起，**不取消任务**，任务继续在后台运行。
- 任务开始 / 结束的提示属于 app 层，走全局提示，不依赖发起任务的页面是否还开着。
- 每个任务 = 一张 `TaskGraph` 的一次运行。卡片是 `FactoryComponent`，列表用
  `FactoryVecDeque` 同步增删；卡片内部用嵌套工厂展示 Step 与任务行。
- 状态只有一份，互斥状态用 enum 表示。Step 计数由任务事件推导；失败计入完成并额外记录
  失败数，取消导致的跳过记为未执行。
- 下载任务数量可能极大，折叠的 Step 不创建任务行；展开时限制渲染数量并固定排序，避免大
  列表卡死界面。
- 日志用 `GtkTextView` 增量追加，不每次重设全文，避免高频进度事件拖慢界面。
- 全局进度只有一条「已下载 / 总字节」，没有确定进度时用不确定进度条。
- `TaskEvent::Warning` 会阻塞等待答复，由任务对话框弹出「继续 / 中止」确认；标题是任务名。
- 退出确认放在任务对话框，因为未结束任务数由它维护；根组件不缓存第二份。
